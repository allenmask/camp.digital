# Client Logos — Source & Usage

Monochrome brand marks for the global "Trusted by" garden, sourced from **Simple Icons v16.30.0**
(https://simpleicons.org). Each is a single-path SVG with no fill attribute, so it inherits
`currentColor` — set one brand ink via CSS (`color`/`fill`) for the single-ink garden the brief specifies.

Included (7): Nike, Apple, Spotify, Google, American Express, Airbnb, The New York Times.

## Notes
- These are **glyph/icon** forms (e.g. the Nike swoosh, Apple mark, NYT "T"). They're a correct,
  consistent starting set for a monochrome garden. If you'd rather show full wordmarks, swap in each
  brand's official wordmark from its press/brand kit before launch.
- **Trademark:** these marks belong to their owners. Showing them is nominative use to identify real
  clients ("trusted by"). Confirm each client is comfortable being named/logoed publicly, and use each
  brand's officially provided asset where a client requires it.
- Simple Icons' SVG data is CC0; the trademarks themselves are not.
